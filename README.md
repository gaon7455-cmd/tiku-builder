# tiku-builder · 把学习通课程做成翻页题库

把一门学习通（超星）课程的习题，变成一个**纯静态、可微信直接打开、永久免费**的翻页题库网站。不用服务器，不用数据库，不用 API Key。

做出来的题库页长这样（参考例子：《化妆品安全使用与功效评价》，87 题）：

- https://gaon7455-cmd.github.io/tiku/huazhuangpin/

功能：黑底白字/纸白/浅灰三档配色切换、左右翻页（一次一道）、单选多选填空判断简答计算连线、做题进度、只看未答/只看答错、题号宫格、左右滑动切题、自评计分、底部留白适配 iPhone 安全区。

## 六步流程

```
课本照片 ──▶ ① 课程识别 ──▶ ② 补充选择 ──▶ ③ 学习通导出
   OCR（可跳过）      只用本课 / 补充外部题     用户自己登录 + 脚本导出 JSON
                                                      │
章节与习题整理 ◀── ④ ──────────────── ⑤ 答案核实 ──▶ ⑥ 生成题库页
官方答案 / 页面未显示标准答案        搜法规原文核实        下载 index.html
（绝不编答案）                        中等置信度标          部署到 GitHub Pages
                                    “依据待确认”
```

1. **课程识别**：上传课本封面/目录照片，用 Tesseract.js（中英文）在浏览器里识别课程名、教师；识别不准可以手动改，也可以跳过识别直接手动填。
2. **补充选择**：先定好——只用本课程习题，还是另外补充外部题库。选了补充，第 4 步可以粘贴或逐条加外部题（标注“外部补充”，不冒充章节原题）。
3. **学习通导出**：这个项目是纯静态页，**登录不了学习通，也绝不会要你的账号密码**。请你自己在浏览器里登录学习通，装 `chaoxing-export.user.js`（Tampermonkey 脚本），打开每个有题的页面点「导出本页习题（JSON）」，再到向导页导入。
4. **章节与习题整理**：按章节列出导入的题。学习通页面直接显示了标准答案的标“官方答案”；页面只显示你的答案和 ✓/✗、没给标准答案的标“页面未显示标准答案”——绝不编造，留到第 5 步。
5. **答案核实**：对每道没答案的题，向导页给出 Bing / Google 搜索链接（按题干自动拼好），你自己查法规、教材、课件原文，把答案和依据贴回来，选置信度（高/中；中等置信度在题库页显示“依据待确认”）。查不到的就留着，生成页会写“页面未显示标准答案”。也可以把待核实清单导出为 JSON（和 `answers-searched.json` 同格式：`[{num, answer, basis, confidence, note}]`）。
6. **生成题库页**：向导页读取 `deck-template.html`，填入课程信息和题目，生成一个独立的 `index.html`，下载后按下面步骤部署。

## 文件说明


## 部署（GitHub Pages，免费）

1. 在 GitHub 新建一个公开仓库，名字叫 `tiku`（已有就不用建）。
2. 把本项目的文件传到仓库根目录（`index.html`、`deck-template.html`、`chaoxing-export.user.js`、`questions.schema.json`、`examples/`）。
3. 仓库 Settings → Pages → Branch 选 `main`，保存。等一两分钟，打开 `https://你的用户名.github.io/tiku-builder/`（仓库名如果是 `tiku-builder`）就能用向导。
   - 向导页和模板必须在同一个网站下（向导页第 6 步用 `fetch('deck-template.html')` 读取模板）。
4. 用向导做完一门课，下载生成的 `index.html`，传到题库仓库（可以是同一个 `tiku` 仓库）里以课程文件夹名新建的文件夹中，例如 `huazhuangpin/index.html`。
5. 在题库仓库首页 `index.html` 加一行链接指向 `huazhuangpin/`。访问 `https://你的用户名.github.io/tiku/huazhuangpin/` 就是这门课的题库。

也可以部署到任何静态托管（Cloudflare Pages、Vercel、Netlify、Nginx），只要向导页和模板在同一域名下。

## 再加一门课

回到向导页第 1 步重新走一遍（先点第 6 步的“清空当前进度”），生成新的 `index.html`，上传到题库仓库里新的文件夹，再在首页加一行链接。模板、脚本、流程都不用改。

## 题目数据格式

见 `questions.schema.json`。要点：

| 字段 | 说明 |
| --- | --- |
| `id` | 题目唯一编号，如 `o1`、`n2`、`e1`、`d0` |
| `src` | `orig` 本课程习题 / `ext` 外部补充题 |
| `type` | `single` 单选、`multi` 多选、`fill` 填空、`judge` 判断、`short` 简答、`calc` 计算、`match` 连线、`discuss` 讨论题 |
| `q` | 题干（填空用 `（ ）` 表示空） |
| `opts` | 选项数组（单选/多选/判断用；判断固定为 `["对","错"]`） |
| `ans` | 答案：选择题是选项下标数组（如 `[1]`）；填空是每空文字数组；连线是配对映射对象 |
| `ansText` | 文字答案（简答/计算/讨论题用） |
| `exp` | 依据/解析：只写标准文案（法规、教材、课件原文） |
| `refTag` / `conf` | 经网络核实的答案写 `refTag: "搜索核实"`；`conf` 为 `high` 或 `medium`（中等置信度显示“依据待确认”） |
| `sec` / `tag` / `ing` / `groups` | 章节、题卡标签、题干补充说明、连线题两组内容 |

**答案规则（底线）：**

- 有官方答案：直接写 `ans` / `ansText`。
- 没官方答案、经网络核实：写 `ans` / `ansText` + `refTag: "搜索核实"` + `conf`。
- 既无官方答案又未核实：**不写 `ans` / `ansText`**，生成页显示“页面未显示标准答案”，且该题不计分、不判对错。

## 诚实限制（先说明白）

- **学习通登录**：静态页登录不了学习通，也不能替你登录。导出全靠你自己登录后用脚本在页面上点按钮。脚本只读已打开的页面，不碰账号密码，不上传任何数据。
- **OCR 准确率**：课本照片识别（Tesseract.js 中英文）只是辅助，错字、漏字很常见；课程名、教师以手动确认的为准。
- **没有自动搜索**：向导页不替你上网查答案。第 5 步只给拼好的搜索链接，查、判断、贴答案都是你自己做。
- **学习通页面会变**：超星经常改页面结构，导出脚本的选择器可能某天失效。失效时脚本仍会把页面全文一起导出，向导页第 3 步可以用“页面全文”方式按行拆成草稿再逐条整理。
- **答案以页面和法规原文为准**：学习通页面本身也会改题、撤课件（例如某节显示“暂无内容”）。导入时以当前页面显示为准，不要凭记忆补写。

## 隐私保证

- 向导页的所有处理都在你的浏览器本地完成：照片 OCR、导入、核实、生成都不经过任何服务器。
- 学习通账号密码只在你自己的浏览器/App 里用，永远不要粘贴到任何页面、不要发给任何人。
- 本项目不收集、不发送、不存储任何个人信息。向导页的进度只存在你自己浏览器的 localStorage 里，随时可以清空。

## 本地测试

```bash
# 在项目目录启动本地服务器（向导页第 6 步要用 fetch 读模板，file:// 打开会失败）
python3 -m http.server 8000
# 打开 http://localhost:8000/ ，第 3 步点“用示例题库试试”，一路走到第 6 步生成并下载。
```

示例题库 `examples/sample-questions.json` 只有 5 道题（公开法规内容，无任何个人信息），其中 1 道是中等置信度（生成页会显示“依据待确认”）。
