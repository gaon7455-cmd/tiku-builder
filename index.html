把学习通课程做成翻页题库

上传课本照片识别课程 → 导出学习通习题 → 核实答案 → 生成和现在这个一样的翻页题库页。六步，全程免费。

隐私保证：全部处理只在你的浏览器里完成，照片、课程信息、习题数据不会上传到任何服务器。本工具绝不索要、绝不保存学习通账号密码——登录请你自己在浏览器或 App 里完成。

拍课本封面或目录页，自动识别课程名和教师；识别不准没关系，下面可以手动改。也可以跳过识别，直接手动填写。

照片只在你的浏览器里识别，不上传。识别用 Tesseract.js（中英文），需要联网加载识别库；加载失败也不影响手动填写。
courseId 在课程链接里能找到（courseId=后面的数字）。没有也不影响，只是导入时方便核对。

只用本课程习题 题库只含学习通里这门课的原题。适合考前只复习本课内容。

STEP 3 · CHAOXING EXPORT学习通导出

这个页面是纯静态的，登录不了学习通（跨域限制），也绝不会要你的账号密码。请你自己在浏览器里登录学习通，再用下面的脚本把习题导出来。

怎么做（5 分钟）

  1. 在电脑浏览器安装 Tampermonkey 扩展（Edge / Chrome 应用商店免费装）。
  2. 下载本项目里的导出脚本 chaoxing-export.user.js，用 Tampermonkey 安装（点链接后按提示点“安装”）。
  3. 在浏览器里自己登录学习通，打开这门课，随便打开一个有习题的页面：章节测验、作业、考试都行。
  4. 页面右下角会出现 「导出本页习题（JSON）」 按钮，点一下就下载一个 JSON 文件。每个有题的页面都导一次（2.3、2.4、4.1……各导一遍）。
  5. 把导出的 JSON 文件（可以一次选多个）在下面导入。
注意：脚本只读你已经打开的页面，不登录、不存密码、不上传、不自动答题、不自动提交、不刷视频。如果某页识别不到题目，脚本会把页面全文一起导出，导入后按下面的“页面全文”方式整理。

STEP 5 · VERIFY答案核实

下面是还没答案的题（学习通页面未显示标准答案）。每道题点开搜索链接自己查，把核实到的答案和依据原文贴回来，选好置信度。查不到、没把握的就留着——生成页会显示“页面未显示标准答案”，不会编一个答案放上去。

没有待核实的题目
导出格式和 answers-searched.json 相同：[{num, answer, basis, confidence, note}]。confidence 填 high（高置信度）或 medium（中等置信度；页面会显示“依据待确认”）。

STEP 6 · GENERATE生成题库页

用 deck-template.html（和现在这个化妆品题库同一套翻页模板）生成一个独立的 index.html，下载后放进你的题库仓库就能用。

生成的文件名固定是 index.html，放在这个文件夹里，访问地址就是 https://你的用户名.github.io/tiku/文件夹名/。

部署到 GitHub Pages（一次设置，以后每个课程照做）

  1. 在 GitHub 新建一个公开仓库，名字叫 tiku（已有就不用建）。
  2. 仓库根目录放一个 index.html 当首页：列出各门课的链接（每门课一行，链到 文件夹名/）。
  3. 把生成的 index.html 上传到仓库里以课程文件夹名新建的文件夹中（和第 6 步填的文件夹名一致）。
  4. 仓库 Settings → Pages → Branch 选 main（或 master），保存。等一两分钟，访问 https://你的用户名.github.io/tiku/文件夹名/ 就能打开。
  5. 微信里直接打开这个链接就能刷题（不用下载任何 App）。

参考例子：化妆品题库 gaon7455-cmd.github.io/tiku/huazhuangpin/（《化妆品安全使用与功效评价》，87 题）。

再加一门课

回到第 1 步重新走一遍（先点下面“清空当前进度”），生成新的 index.html，上传到仓库里新的文件夹，再在首页加一行链接。模板、脚本、流程都不用改。
